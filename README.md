Velvet Vault is a top-down stealth heist game: case three jobs — a museum gallery, a bank vault and a sky penthouse — dodge guard vision cones and sweeping security cameras, hack the cameras, lift the paintings, gold and the Aurora Diamond, and slip out before the alarm meter maxes out. All art is procedural canvas drawing and all sound is synthesized WebAudio; it runs from static files with no network.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys, hold Shift to sneak, hold E near loot to pick the lock, near a camera to hack it, or in a vent to crawl through it. Grab every target, then reach the exit.
